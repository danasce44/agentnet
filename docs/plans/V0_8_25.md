## Scope

Comic is the only embedded skin. Classic and Zoom become ordinary installed
packages, alongside Holonet and Pulp in the published collection. A formerly
selected built-in Classic or Zoom safely falls back to Comic until installed.

Settings → Appearance offers the latest published gallery, verified previews,
per-file hashes and the package digest. Installation is browser-local and does
not select the package or grant trust. The existing trust step applies before
use. Packages requiring a newer AgentNet cannot be selected. Requests use the
fixed GitHub repository without credentials or referrers.

The Comic kit exposes presentation slots and documented parts for overlays;
Pulp changes those slots while reusing Comic's interactions. Host API routes,
native visibility and presentation contracts are documented and checked against
source. No message transport, identity, roster, native harness permissions,
schema or server service is changed.

### Integrated failures and bounded corrections

The macOS deletion fixture started a newly linked current daemon before
publishing simulated older-reader capabilities. Its sender could replay the
deletion in that interval. The corrected fixture receives the pending link
first, stops that sender, approves/starts the phone, publishes older-reader
capabilities, then resumes the sender. All deletion, non-resurrection and
capability-wake assertions remain. Three local race repetitions pass 16.622 s.
An initial probe stopped the sender before the link request could arrive and
failed at that setup boundary; its failed log is retained, not counted as a pass.

Windows' initial failure waited for Carol's group state; its focused rerun
failed at a later phone convergence. Deferred diagnostics showed that phone
eventually had the requested sequence, but did not prove when it arrived.
The existing wait repeatedly opened the full client, including startup recovery,
instead of observing through one API handle. The fixture now uses one observer
for each wait and logs wanted/observed hashes and sequence at failure. The same
15-second convergence assertion remains. Three local repetitions pass 10.998 s;
native follow-up passes on all supported systems. No production group behavior
is changed. Claude's independent review confirms each repeated Open previously
acquired immediate SQLite write transactions for startup recovery; a held
observer sees new WAL commits without a long transaction. This establishes
observer interference, not a complete proof of the earlier transport delay.

Client4 reached its package alarm with TestWorkspacesTwoIndependentMembershipsRestart
running for one second. The full log reports no data race or earlier failed
assertion. That timeout is not a pass; the required bounded follow-up runs
all 96 assigned tests and passes 515.426 s. The other eleven partitions stay
qualified. No timeout was increased and the full failed run remains retained.

## Limits and operations

No physical-phone timing, Play Store publication or signed desktop installer
is claimed. Gallery availability depends on GitHub; saved/installed packages
and Comic remain local. A skin is trusted code with page access: checksums
establish byte integrity, not safety. No live request is replayed, no identity
is reset and no OS permission is changed by qualification.

Relay deployment is separate from artifact publication and requires current
owner authorization. The existing relay remains on v0.8.24 until deployment.
Laptop-only leftover worktrees in Claude's handoff are not remotely removed
without reachable-machine inspection and authorization.
