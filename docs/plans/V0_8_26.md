## Problem and scope

The released v0.8.25 Android APK renders “The skin gallery could not be reached”
in Appearance. Its WebView interceptor refuses every non-loopback request,
including the new gallery's fixed GitHub fetches. The initial APK qualification
covered preservation and native updates but missed this new feature. Actual APK
failure evidence is `/tmp/agentnet-v25-gallery-appearance.xml`; Claude's review
is `ANDROID_GALLERY_1fa4`. Desktop and browser galleries are unaffected.

The correction changes only `MainActivity.kt`, `WebPolicy.kt` and their focused
policy tests. The existing interceptor permits GET subresources for the exact
`api.github.com/repos/misunders2d/agentnet-skins/releases/latest` endpoint and
files inside `raw.githubusercontent.com/misunders2d/agentnet-skins/`.
HTTPS/default TLS port, no userinfo/query/fragment and safe path segments are
required. Other sources, verbs, main-frame navigation and native bridge access
retain their existing checks. Gallery CORS, CSP, omitted credentials/referrers,
redirect refusal, per-file SHA-256, package digest and explicit trust remain.
No Go/client/Hub/browser host code, schema, messaging or harness permissions
change. The skin changes are in the existing agentnet-skins checkout. No new
product dependency or service is introduced. The explicitly assigned v0.8.27
worktree stays separate and is excluded from this release.

## Skin corrections

Classic, Holonet and Zoom now have a visible Settings item that opens Appearance;
You opens Profile. Zoom's person and chat rows open the conversation with its
Write control, rather than the single-message view. Reply returns to the chat
and keeps the quoted message. Conversation mute and the existing optional
Project space control remain reachable on phones and in Zoom's chat view.

The candidate also corrects own-agent default reply routing, captured assistant
identity across retries, topic selection feedback, dismissed-agent controls,
Holonet reminders and long links, and phone touch/keyboard layout. The keyboard
regression includes an active admitted agent at 390×480. No received message
gains execution authority and no native harness permission changes.

Claude's frozen interaction inventory covers Comic, Pulp and the three standalone
skins. The first full collection run preserved three failures: a Classic touch
fixture redraw race, a real early-overview Zoom crash, and a Zoom touch fixture
that selected another person's bubble. Focused final-build checks correct these;
the original failure records are retained. Codex's final review additionally
found failed-send draft persistence calls hidden by a production inline comment
and an empty newer-target restoration case. Both are corrected in all three
skins: failed sends restore only to an eligible empty original target, otherwise
retaining the captured Retry. New regressions prove restored drafts and newer
targets survive reopening. A fresh disposable world passed contract, lifecycle,
browser, browser-provider and touch checks for every standalone skin. The owner's
subsequent Pulp avatar refinement awaits his selection and its focused gate.
