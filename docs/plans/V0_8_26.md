## Shipped behavior

Android's gallery permits GET subresources only from the exact GitHub latest
collection endpoint and files within `misunders2d/agentnet-skins`. HTTPS, safe
paths and the existing CORS/CSP, digest and explicit-trust checks remain. Other
hosts, verbs, credentials, query strings, main-frame navigation and bridge
access retain their checks. The application correction changes only three
Kotlin source/test files; Go/client/Hub/host code and native harness permissions
are unchanged from v0.8.25.

Classic, Holonet and Zoom have labelled Settings controls and usable phone
navigation. Zoom opens a chat from its person/chat rows, preserves Reply's
quoted message and keeps the existing Write action in a sticky header through
long DM/device histories. A single resize observer follows headers replaced
by search; focus padding remains correct after search clearing and resize.
Send/retry captures the original assistant and target, preserving newer drafts.
Topic controls, mute, reminders and existing Project space stay reachable.
Permission descriptions correctly state unchanged native tools and own-device
consent. Pulp includes the owner's selected hairstyle refinement.

No new transport, service, product dependency, permission override or execution
authority is introduced. v0.8.27's separate worktree is excluded.
